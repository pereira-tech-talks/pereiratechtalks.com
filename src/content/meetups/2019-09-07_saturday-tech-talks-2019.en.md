## Pereira - Saturday Tech Talks

📣 A big event organized by all of Pereira's technology communities. Excellent
talks you should not miss:

🔎 Next.js lets you build a React web application rendered on the server side. We
look at the advantages of rendering server-side versus rendering client-side (in
the browser), and how Next.js can live with both.

### Talks

1. **Next.js: Server-side rendering your React App** — Andrés Rodriguez Escudero ([profile](https://twitter.com/arodrigueze_))
2. **Introduction to Amazon Web Services (AWS)** — Steven Pineda Cortes ([profile](https://twitter.com/Steven2308))
3. **Architecture patterns — Android** — Zorayda Gutiérrez Montes ([profile](https://www.facebook.com/zoraidayadi.gutierrezmontes))
4. **Serverless development of conversational interfaces on Amazon Alexa and Google Home** — Sergio Alexander Florez Galeano
