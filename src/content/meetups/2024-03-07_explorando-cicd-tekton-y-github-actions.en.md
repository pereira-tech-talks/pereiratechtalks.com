## Exploring CI/CD: Tekton on Kubernetes and GitHub Actions

**Talk 1: Introduction to Tekton CI/CD**

An introduction to the core concepts of Tekton, an open source solution for CI/CD
on Kubernetes.

*Speaker: Andrés Torres.*

*Software Engineer, **Broadcom***

**Talk 2: Automating your workflow: an introduction to GitHub Actions and CI/CD**

Join this introductory session on how GitHub Actions can transform your
development and continuous deployment process. From basic setup to building
custom workflows, you will learn how to get the most out of this powerful tool.

*Speaker: Hector Fabio Jimenez S*

*Site Reliability Engineer, **GoDaddy.***
