## Testing Night — unit tests in Python and JavaScript

Unit tests exist to make development reliable, quick, and efficient. Writing them
as you build is how teams raise confidence in the code they write and ship to
production constantly and safely.

At our next meetup we have two talks introducing the world of unit testing,
focused on two completely different languages currently used to build web
applications: JavaScript on the client, and Python on the server.

### Talks

1. **Unit tests in JavaScript** — John Darwin Morales ([profile](https://twitter.com/jdmorales092))
2. **Unit tests in Python** — Carlos Álvaro ([profile](http://caal-15.github.io/#programming))
