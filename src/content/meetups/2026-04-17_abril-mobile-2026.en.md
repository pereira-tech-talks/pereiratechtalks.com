## April Mobile

On April 17, 2026 we gathered at **Universidad Tecnológica de Pereira** for
**April Mobile**. On the programme: Sergio Alexander Flórez, Juan Diego
Campuzano.

Mobile development month: Kotlin Multiplatform, native vs. cross-platform, and
where mobile is heading in 2026.

### Talks

**Discovering Kotlin Multiplatform**

**Speaker:** Sergio Alexander Flórez

Let's learn Kotlin Multiplatform from scratch. We explore a different way to build for Android and iOS — sharing code where it adds real value without stepping away from native tooling and developer experience — while uncovering why this technology is gaining so much traction in the mobile world.

**Liquid interfaces — using GenUI to personalize your Flutter app**

**Speaker:** Juan Diego Campuzano

Take your mobile apps to the next level with Generative UI in Flutter. This talk shows how the flutter_genui package lets models like Gemini orchestrate native widgets in real time so the app personalizes itself with dynamic interfaces built around each user's preferences.
