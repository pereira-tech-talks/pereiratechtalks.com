## Learning about JWT (JSON Web Tokens)

At the first gathering of 2017 we were glad to be at the Belmonte campus on
February 28, with students, teaching staff, and graduates of the Systems
Engineering programme there and at other universities.

[Carlos González](https://www.facebook.com/CarloS.GonzaleZ.E) talked about JSON
Web Tokens in NodeJs — an open standard defining a compact, secure way to
transmit information between parties as JSON objects, commonly used for
authentication and for exchanging information over an insecure channel.
