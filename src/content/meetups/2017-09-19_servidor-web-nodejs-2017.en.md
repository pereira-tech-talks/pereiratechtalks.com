## Building a web server from scratch with NodeJs

The Universidad de Caldas invited us to run a workshop at the Jornadas de
Ingeniería Sociedad + Educación on building a web server from scratch, without
frameworks, using NodeJS modules. Led by
[John Darwin Morales](https://twitter.com/jdmorales092) and Sergio Alexander
Florez.

Slides available at: http://slides.com/rockalabs/creando-un-servidor-web-con-nodejs#/
