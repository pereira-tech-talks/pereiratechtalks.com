## 3. Goal

Create a print-perfect, edition-aware visual foundation for diplomas that feels premium and on-brand.

## 4. Instructions

> **Before starting:** Re-read the plan README section 1 (Goal) to ensure this task's work aligns with the overall objective.

1. Study PR #297 CSS but rebuild with PTT + edition tokens; avoid Roboto/emoji aesthetic.
2. Landscape A4 aspect-ratio 297/210; generous margins; WCAG for on-screen chrome; print hides chrome.
3. Support light presentation for print (certificates are typically light even in dark mode site) — decide and document.
4. Motifs: subtle edition hero watermark, community mark row, seal, QR zone — no floating promo badges.
5. prefers-reduced-motion for any decorative animation on screen.
6. Write CERT_VISUAL_BRIEF.md with composition rules (hero budget for the diploma itself).
