## 3. Goal

Define privacy rules, opaque ID format, robots/noindex policy, and what is never published (emails, listings).

## 4. Instructions

> **Before starting:** Re-read the plan README section 1 (Goal) to ensure this task's work aligns with the overall objective.

1. Reject sequential guessable IDs; specify opaque format (e.g. cert_ + base32/nanoid) and collision checks.
2. Define which fields appear on diploma vs JSON-LD vs never stored (email optional in private import side-file only — prefer NOT in git registry).
3. Specify no public /certificates index of people; event landing may explain how certificates work without listing names.
4. robots: noindex for personal cert pages; verify pages may be indexable or noindex — decide and justify.
5. Document revocation/replacement UX copy requirements for both languages.
