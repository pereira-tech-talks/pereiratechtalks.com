## 3. Goal

Ship `pnpm run certs:import` that turns an attendee CSV into a registry file with opaque IDs and dedupe rules.

## 4. Instructions

> **Before starting:** Re-read the plan README section 1 (Goal) to ensure this task's work aligns with the overall objective.

1. CSV minimum columns: name (required), role (optional), certificate_id (optional).
2. Generate opaque IDs when missing; never use pure sequential public IDs.
3. Normalize whitespace/Unicode names carefully; flag duplicates for human review.
4. Write registry to path decided in ADR; do not commit real attendee CSVs.
5. Document CLI usage in script --help and briefly in task log.
6. Unit-test ID generation uniqueness and CSV parsing edge cases.

- pnpm run test passes.
