# Plan: Certificate Generation System (Static Verifiable Diplomas)

## 1. Goal

Integrate a **world-class, fully static certificate / diploma system** into Pereira Tech Talks v3 so attendees of flagship events (especially **Pereira Tech Day**) receive a premium printable diploma with QR-based public verification — generated at **build time** from an attendee registry, optionally as **W3C Verifiable Credentials 2.0** signed with Ed25519 under `did:web:pereiratechtalks.org`, with bilingual pages and per-edition brand kits — **without a runtime backend**.

Elevate the approach in [PR #297](https://github.com/pereira-tech-talks/pereiratechtalks.com/pull/297) (`Feature/cert` + Nivel-2 static plan) to v3 architecture, design system, and operational quality.

**Rigor tier:** `deep` — cryptography, PII, new public routes, CI secrets, print-grade UI.

Every plan includes Security Review (third-to-last), Skills & Agents Discovery (second-to-last), and Executive Report (last). These are auto-generated by `/dwp-create`.

## 2. Context

- **Repo:** `/app` — Astro 7 SSG, Svelte 5, Tailwind 4 PTT tokens, Biome, Vitest, Cloudflare Pages.
- **Legacy reference:** PR #297 on `pereiratechtalks.com` — visual certificate + `PLAN-CERTIFICADOS-NIVEL-2-ESTATICO.md`. Local git ref: `tmp/pr297-cert-branch`.
- **Refined draft:** `.dwp/drafts/PLAN_certificate_generation_system_draft_refined.md`
- **Product constraint (user):** static site → static collection/pages from attendee list; look *bien pro*.
- **i18n:** ES primary `/`, EN `/en`; Page Wrapper pattern; orthography mandatory.
- **Theming:** Global PTT + `EditionScope` / `brandKit` for PTD editions.
- **Out of scope:** blockchain Level 3, realtime check-in, admin portal, automatic email, runtime revocation API.

### Architecture sketch (target)

```text
CSV/Sheets (post-event) → certs:import → registry (validated)
       → certs:sign (CI secret Ed25519) → public/certificates/{event}/{id}.json
       → Astro getStaticPaths → /…/certificates/{id} + /…/verify/{id} (ES+EN)
       → QR → verify page → Web Crypto + did:web
```
