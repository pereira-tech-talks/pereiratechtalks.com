# /lib-upgrade — provided by the `deepworkplan` dependency-upgrade addon

> Thin delegator. The upgrade logic lives in the installed `deepworkplan` skill's
> dependency-upgrade addon — this file only routes to it.

Bring this repository's dependencies up to date **without breaking the build**.

## Steps

1. Invoke the `deepworkplan-addon-dependency-upgrade` addon — read
   `.agents/skills/deepworkplan/addons/dependency-upgrade/SKILL.md` and follow it.
2. Follow the addon's flow: detect this repo's package manager
   (**pnpm**, via `pnpm-lock.yaml` + `pnpm run ncu:check`), classify upgrades
   (patch/minor/major), upgrade in safe batches, run this repo's **real**
   validation gate after each batch
   (`pnpm run biome:check && pnpm run astro:check && pnpm run test && pnpm run build`),
   revert any batch whose gate fails, and summarize.
3. Surface the upgrade report and the diff; do **not** auto-commit.

## Notes

- Detected package manager for this repo: **pnpm** (`pnpm-lock.yaml`).
- Real validation gate: `pnpm run biome:check`, `pnpm run astro:check`,
  `pnpm run test`, `pnpm run build` (see `docs/DEVELOPMENT_COMMANDS.md`).
- Majors require explicit approval before they are included in a batch.
- The lockfile is regenerated by pnpm — never hand-edit `pnpm-lock.yaml`.
